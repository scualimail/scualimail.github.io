Tool options

Brush
Drag to draw. Drag up or left to flip the shape. Open shapes (lines, arrows) are always outlined. Option changes apply to the selected shape layer; select another layer to set options for a new shape.
3D+ shapes are rendered as real, lit 3D objects. Drag to draw, then change the angles. The layer is re-rendered sharp when you resize it with the Move tool.
Click to fill a similar-coloured area of the active layer.Click to select a similar-coloured area of the layer under the cursor. Hold Ctrl to add more areas. Tick All layers to ignore layer boundaries.Drag to draw a gradient on a new layer (inside the selection, if there is one).
Click the canvas to place new text. To edit, select a text layer with the Move tool (or click it with this tool).
Drag to select. Drag inside a selection to move it, or drag its square handles to resize it (Shift keeps the proportions). Brush and eraser only affect the selected area.
Drag a box, drag its square handles to resize, drag inside it to reposition (arrow keys nudge, Shift = 10 px). Apply or press Enter. Circle keeps the box square.
Drag to move. Corners scale (Shift = free). Top handle rotates (Shift = snap).

Selection

Make a selection, then Ctrl+C to copy it from the selected layer (Ctrl+Shift+C for everything visible) and Ctrl+V to paste.
